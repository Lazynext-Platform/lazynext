## Duplicate / Slug-Order Notes

### `ad-creative-*` vs `creative-ad-*` Slug-Order Inconsistency

The codebase contains **two parallel naming conventions** for persuasion/psychology-framework designer pages:

- **`ad-creative-*`** — 46 pages (e.g. `ad-creative-tension-release-designer`)
- **`creative-ad-*`** — 35 pages (e.g. `creative-ad-tension-release-strategist`)

These are **not exact duplicates** — each set covers distinct psychological/narrative concepts. However, the reversed slug order (`ad-creative-` vs `creative-ad-`) is an inconsistency that should be normalized during the transformation. The closest conceptual overlap is:

| `ad-creative-*` | `creative-ad-*` | Notes |
|-----------------|-----------------|-------|
| `ad-creative-tension-release-designer` | `creative-ad-tension-release-strategist` | Same concept (tension-release), different suffix (`designer` vs `strategist`) |

All other concepts across the two sets are unique to their respective prefix group.
