- **Cofounder/Cofounder.co** → normalized to Cofounder.co
- **Locus/Locus Founder** → normalized to Locus Founder
- **VentureCity** → normalized to Venture City
- **Makerpad** → normalized to MakerPad
- **AI Cofounder** (PDF row) → current brand/site verified as Buildpad
- **Collision** → domain currently parked/for sale; active platform site not verified
- **Ceres / Sapphire** → no confident current official platform website verified;
  URL cells intentionally blank rather than using an unrelated site
- Only platform/company names visibly written in the supplied PDF were included;
  generic tools, source labels, and supporting services were not added merely
  because they appeared in descriptive text
