## Recovery Procedures Verified

### D1 Point-in-Time Recovery

**Procedure:** Cloudflare D1 provides automatic point-in-time recovery. To restore:
1. `npx wrangler d1 export lazynext-db --remote --output backup.sql`
2. Create new D1 database: `npx wrangler d1 create lazynext-db-recovery`
3. Import: `npx wrangler d1 execute lazynext-db-recovery --remote --file backup.sql`
4. Update wrangler.jsonc to point to recovery database
5. Redeploy Worker

**Verified:** Export step completed successfully (86 KB, 57 tables, 188 rows).

### R2 Object Recovery

**Procedure:** R2 provides object versioning. To restore a deleted object:
1. List versions: `npx wrangler r2 object list <bucket> --remote`
2. Restore previous version: `npx wrangler r2 object put <bucket>/<key> --file <local-file>`

**Not verified in this drill** — R2 recovery requires a staging bucket to test safely.

### Worker Redeployment

**Procedure:** To roll back to a previous Worker version:
1. `npx wrangler deployments list` — list recent deployments
2. `npx wrangler rollback` — roll back to previous version

**Verified:** Current deployment version `a83061ce` is active and healthy.
